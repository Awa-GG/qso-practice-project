 QSO Practice Project

 About the Project

The QSO Practice Project is a beginner web development project created by Awa Gaye. Its purpose is to practise HTML, learn how websites are organized, and build a foundation for a future career in web development.

The website contains four HTML pages. Each page has a different purpose, making the project easy to explore.

 Project Files

| File or Folder  | Purpose                                                              |
| --------------- | -------------------------------------------------------------------- |
| `index.html`    | The homepage introducing the website and linking to the other pages. |
| `about.html`    | Provides information about the project and its author.               |
| `projects.html` | Describes learning activities and planned web development projects.  |
| `contact.html`  | Explains the purpose of the contact section.                         |
| `images/`       | Stores images used on the website.                                   |
| `css/`          | Stores CSS files for styling the website.                            |
| `js/`           | Stores JavaScript files for interactive features.                    |
| `README.md`     | Explains the project, its files, and its author.                     |

 How to Open the Project

1. Download or clone the repository.
2. Open the `qso-practice-project` folder.
3. Open `index.html` in a web browser.
4. Use the navigation links to visit the other pages.

No additional software is required to view the basic HTML pages in a modern web browser.
